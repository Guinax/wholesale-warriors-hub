# Mansão Maromba — Wholesale Warriors Hub

Aplicação oficial da Mansão Maromba / Família Maromba.

## Produção

- Hospedagem: Vercel
- Repositório fonte: `Guinax/wholesale-warriors-hub`
- Branch de produção: `Main`
- Backend, autenticação e banco: Supabase

## Desenvolvimento local

```sh
git clone https://github.com/Guinax/wholesale-warriors-hub.git
cd wholesale-warriors-hub
npm i
npm run dev
```

## Publicação

As alterações devem ser feitas no GitHub. A Vercel publica automaticamente a branch `Main`.

## Estrutura principal

- catálogo e páginas de produtos
- carrinho e checkout
- pedidos e rastreio
- cadastro e login
- painel administrativo
- painel de revendedores
- rede de parceiros e estoque unificado
- integrações de pagamento e frete
